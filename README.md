# DecodeLabs Backend API - Project 2

> A RESTful API demonstrating backend development fundamentals with data validation and proper HTTP status codes.

## 📋 Project Overview

This project implements a simple user management API as part of DecodeLabs Full Stack Development training. It demonstrates:

- **GET endpoints** for retrieving user data
- **POST endpoints** for creating new users  
- **Data validation** following the "Never Trust the Client" principle
- **Proper HTTP status codes** (200, 201, 400, 404)
- **JSON data exchange** format

## 🚀 Quick Start

### Prerequisites

- [Node.js](https://nodejs.org/) (v14 or higher)
- [npm](https://www.npmjs.com/) (comes with Node.js)
- [Postman](https://www.postman.com/) (optional - for testing)

### Installation

```bash
# Clone or download this project
cd decode-api-project

# Install dependencies
npm install express

# Start the server
node server.js
